# Portfólio de Lucas Franzen Nori

Site estático em português, pronto para ser servido pelo GitHub Pages. O conteúdo foi baseado no currículo e nas informações complementares fornecidas pelo proprietário. A imagem do Marfran Imports é uma captura da versão local em desenvolvimento; Docker e VPS são planos de publicação do projeto, não tecnologias já implantadas.

## Publicar no GitHub Pages

1. Envie `index.html`, `styles.css`, `script.js`, `favicon.svg`, `.nojekyll` e a pasta `assets` para a raiz de um repositório no GitHub.
2. Em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch principal e a pasta **/(root)**. Salve e aguarde a URL do Pages aparecer nessa tela.

O site usa caminhos relativos, por isso funciona tanto em um repositório de projeto quanto em um repositório `<usuario>.github.io`. As fontes do Google Fonts são opcionais; fontes de sistema são usadas como alternativa.

## Prévia local

Abra `index.html` no navegador ou sirva a pasta com um servidor estático local.
